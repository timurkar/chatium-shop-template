# Шаблон интернет-магазина

Готовый интернет-магазин на Chatium: каталог с категориями, поиском и сортировкой, карточка товара,
корзина без регистрации, оформление заказа и панель управления для сотрудников.

## Структура

Два независимых воркспейса (папки на корне аккаунта). Их можно переносить в другие аккаунты
и объединять с другими шаблонами — каждый воркспейс виден в панели Chatium отдельно.

- **`shop/`** — витрина, доступна по адресу `/shop`
- **`shop-admin/`** — панель управления, `/shop-admin` (роль Staff и выше); зависит от `shop/`
  (импортирует таблицы, серверные хелперы и общие компоненты по пути `../shop/...`)
- `index.tsx` в корне просто перенаправляет `/` на `/shop`

| Страница | Файл | Описание |
| --- | --- | --- |
| `/shop` | `shop/index.tsx` | Главная: hero, категории, хиты продаж, новинки |
| `/shop/catalog` | `shop/catalog.tsx` | Каталог с фильтром по категории, поиском и сортировкой |
| `/shop/product?id=…` | `shop/product.tsx` | Карточка товара и похожие товары |
| `/shop/cart` | `shop/cart.tsx` | Корзина (localStorage) и форма оформления заказа |
| `/shop/order?id=…` | `shop/order.tsx` | Страница принятого заказа |
| `/shop/seed` | `shop/seed.tsx` | Наполнение демо-данными (идемпотентно: работает только на пустом каталоге) |
| `/shop-admin` | `shop-admin/index.tsx` | Товары, заказы, категории |
| `/shop-admin/product?id=…` | `shop-admin/product.tsx` | Создание и редактирование товара с загрузкой фото |

```
shop/
  tables/       таблицы Heap: категории, товары, заказы
  api/          публичные JSON-роуты: categories/list, products/{list,get,by-ids}, orders/{create,get}
  server/       серверная логика: сериализация, фильтры, создание заказа, демо-данные
  shared/       код для сервера и браузера: настройки магазина (config.ts), корзина (cart.ts)
  pages/        Vue-страницы, components/ — шапка, подвал, карточка товара, степпер, иконки
  layout.tsx    HTML-оболочка страницы, styles.tsx — подключение Tailwind
shop-admin/
  api/          защищённые роуты: products/{create,update,delete,admin-list}, categories/*, orders/*
  pages/        DashboardPage.vue (товары/заказы/категории), ProductFormPage.vue (форма товара)
  components/   AdminHeader.vue
```

## Быстрый старт

1. Откройте сайт и нажмите «Наполнить демо-данными» (или откройте `/shop/seed`).
2. Зайдите в `/shop-admin` под пользователем с ролью **Staff** или выше — добавьте свои товары
   и категории, загрузите фото.
3. Настройте магазин в `shop/shared/config.ts`: название, описание, контакты, стоимость и порог
   бесплатной доставки, валюту.

## Как это устроено

- **Цены** хранятся как `Heap.Money` и форматируются на сервере (`priceFormatted`); клиент получает
  и число, и готовую строку.
- **Корзина** живёт в `localStorage` (`shared/cart.ts`) и не требует входа. Актуальные цены и остатки
  подтягиваются через `shop/api/products/by-ids`.
- **Заказ** создаётся в `server/order-data.ts`: цены и наличие берутся из базы, а не из запроса;
  остатки списываются; доставка считается по правилам из `shared/config.ts`.
- **Публичные и админские чтения** разделены: публичные роуты отдают только товары со статусом
  `active`, админские (`shop-admin/api/products/admin-list`, страница `/shop-admin`) — все.
- **Доступ** к админке и мутациям защищён `requireAccountRole(ctx, 'Staff')` в каждом обработчике.
- **Фото товаров** загружаются в хранилище Chatium из формы товара; хранится только хеш файла,
  превью строится через `getThumbnailUrl`. Без фото карточка показывает эмодзи на градиенте.

## Что легко доработать

- Оплата: добавьте поле `payment` в `shop/tables/orders.table.ts` и шаг оплаты в `CartPage.vue`.
- Уведомления о заказе: вызовите отправку письма/сообщения после `Orders.create` в
  `shop/server/order-data.ts` (или через фоновую задачу `app.job`).
- Личный кабинет: свяжите заказ с пользователем через `Heap.UserRefLink` и добавьте страницу «Мои заказы».
- Несколько фото: замените `imageHash` на `Heap.Array(Heap.String(...))`.

## Публикация

Репозиторий синхронизирован с аккаунтом Chatium через Source Git: `git push origin main`
публикует изменения в production, push в другую ветку — версию для предпросмотра
(`?__chtmPreviewMode__=account:<branch>`). Проверка типов: `npm run typecheck`.

> Имена папок на корне аккаунта не должны совпадать с системными префиксами платформы
> (`api`, `app`, `account`, `user`, `feed`, `chat`, `inbox`, `entity`, `editor`, `logic`, `payment`,
> `static`, `s`) — внутри воркспейса таких ограничений нет.
